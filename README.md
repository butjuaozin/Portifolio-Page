🎯 Objetivo do Projeto

Desenvolver e publicar um portfólio profissional online, apresentando projetos e informações pessoais de forma organizada e acessível pela web.

🧩 Dificuldades Conhecidas
- Organização das informações e projetos no portfólio.
- Estruturação da página em HTML.
- Criação de uma navegação simples e intuitiva.
- Publicação e disponibilização do site na internet.
- Organização e atualização do conteúdo do portfólio.

🛠️ Etapas do Desenvolvimento
- Planejamento da estrutura do portfólio.
- Criação da página principal em HTML.
- Organização das informações e projetos.
- Implementação da navegação entre conteúdos.
- Ajustes visuais e de organização da página.
- Criação do repositório no GitHub.
- Publicação do portfólio utilizando GitHub Pages.
- Testes de acesso e funcionamento do site.
- Atualização e manutenção do conteúdo.

🔧 Tecnologias e Serviços Utilizados
- HTML
- Git
- GitHub
- GitHub Pages
